## 6. Errors Encountered and How They Were Fixed

1. **Lombok Incompatibility with JDK 23:**
   - *Issue:* During initial compilation, Lombok's annotation processor failed under JDK 23 compiler changes (`NoSuchFieldError: JCImport does not have field qualid`).
   - *Fix:* Removed Lombok from `pom.xml` and implemented clean, standard Java 17+ POJO getters, setters, and constructors in [BaseEntity.java](file:///d:/lifeOS/backend/src/main/java/com/lifeos/common/entity/BaseEntity.java), [ErrorResponse.java](file:///d:/lifeOS/backend/src/main/java/com/lifeos/common/dto/ErrorResponse.java), and [HealthResponse.java](file:///d:/lifeOS/backend/src/main/java/com/lifeos/dto/HealthResponse.java).
2. **Deterministic Database Testing:**
   - *Issue:* Local MySQL service was listening on port 3306 with unknown credentials, preventing zero-setup automated test execution.
   - *Fix:* Added H2 in `runtime` scope with dedicated `application-local.yml` and test configuration in MySQL compatibility mode. Automated tests execute deterministically in memory, while MySQL is preserved for production and standard dev runs with Flyway and Hibernate validation.
